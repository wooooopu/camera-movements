## 1. 四大核心運鏡與經典影視案例（含片段觀賞）

### 1.1 Pan（水平運鏡 / 水平搖鏡）
* **物理本質**：機位固定不動，鏡頭水平向左或向右旋轉（Yaw 軸旋轉）。
* **人體比喻**：如同站在原地轉動脖子環視四周。
* **專屬詳解文檔**：[content/cases/pan.md](file:///d:/鏡頭語言重點%20工作資料/content/cases/pan.md)

#### 🎬 經典影視案例與線上影片觀看：

1. **《火車大劫案》(The Great Train Robbery, 1903)**
   - **導演**：Edwin S. Porter ｜ **攝影**：Blair Smith
   - **官方海報**：[查看 1903 原版海報](https://upload.wikimedia.org/wikipedia/commons/thumb/e/e2/Great_Train_Robbery_Poster.jpeg/800px-Great_Train_Robbery_Poster.jpeg)
   - **經典場景**：劫匪在山林逃跑時，攝影機第一次打破固定腳架的束縛，左右水平平移追隨劫匪的馬匹。
   - **鏡頭語言解析**：影史上首個被記載的 Pan 鏡頭。宣告連續影像不再只是被動記錄舞台劇，而能自主引導觀眾視線。
   - 🔗 **線上影片觀賞**：[▶ 點此觀看《火車大劫案》公有領域原版完整片段 (210秒處起)](https://www.youtube.com/watch?v=-WYYtN13Vfk&t=210s)

2. **《布達佩斯大飯店》(The Grand Budapest Hotel, 2014)**
   - **導演**：Wes Anderson (韋斯·安德森)
   - **官方海報**：[查看粉色大飯店經典海報 (TMDB)](https://image.tmdb.org/t/p/w500/eWdyYQreja6JGCzqHWXpWHDrrPo.jpg)
   - **經典場景**：大堂經理古斯塔夫與門童零（Zero）在大廳中對話，鏡頭以極快的速度進行 90 度與 180 度的甩鏡（Whip Pan）。
   - **鏡頭語言解析**：極速水平橫搖打破了傳統正反打剪輯，以超高機械式節奏營造強烈的童話感、對稱美學與荒謬喜劇張力。
   - 🔗 **線上影片觀賞**：[▶ 前往觀看安德森經典極速甩鏡片段 (15秒處起)](https://www.youtube.com/watch?v=RK4NNe3zHbc&t=15s)

3. **《羊男的迷宮》(Pan's Labyrinth, 2006)**
   - **導演**：Guillermo del Toro (吉勒摩·戴托羅)
   - **官方海報**：[查看迷宮原版海報 (TMDB)](https://image.tmdb.org/t/p/w500/oDqwyEUd0Q22wjnjRLn4NENiMPu.jpg)
   - **經典場景**：攝影機從現實世界中軍官冰冷殘酷的房間，平緩橫搖穿過一根厚實的石柱或牆面，移出時瞬間無縫轉換到地底奇幻迷宮。
   - **鏡頭語言解析**：利用「遮擋橫搖（Wipe Pan / Seamless Pan）」作為場景轉場，讓現實的冷酷與幻想的詭譎在同一個呼吸中完成切換。
   - 🔗 **線上影片觀賞**：[▶ 前往觀看石柱無縫橫搖遮擋轉場解析 (112秒處起)](https://www.youtube.com/watch?v=IiyBo-qLDeM&t=112s)

### 1.2 Tilt（垂直運鏡 / 俯仰運鏡）
* **物理本質**：機位固定不動，鏡頭垂直向上仰起或向下俯視（Pitch 軸旋轉）。
* **人體比喻**：如同人類抬頭仰望天空（Tilt Up）或低頭看地（Tilt Down）。
* **專屬詳解文檔**：[content/cases/tilt.md](file:///d:/鏡頭語言重點%20工作資料/content/cases/tilt.md)

#### 🎬 經典影視案例與線上影片觀看：

1. **《刺激1995》(The Shawshank Redemption, 1994)**
   - **導演**：Frank Darabont ｜ **主演**：Tim Robbins
   - **官方海報**：[查看安迪暴雨仰望經典海報 (TMDB)](https://image.tmdb.org/t/p/w500/9cqNxx0GxF0bflZmeSMuL5tnGzr.jpg)

   - **鏡頭語言解析**：從被禁錮的地面仰升至自由的蒼穹，將安迪二十年漫長痛苦的釋放、救贖與神聖重生的心理狀態推向影史頂點。

### 1.3 Boom / Crane（升降運鏡 / 搖臂運鏡）
* **物理本質**：攝影機整機在垂直空間中實體升起或下降（Z/Y 軸垂直空間位移）。
* **人體比喻**：如同搭乘透明電梯，在空間高度中漂浮。
* **專屬詳解文檔**：[content/cases/boom.md](file:///d:/鏡頭語言重點%20工作資料/content/cases/boom.md)

### 1.4 Dolly / Truck（水平軌道運鏡 / 推拉橫移）
* **物理本質**：攝影機實體架設於推車或軌道上，在水平空間中進行前後推拉（Dolly In/Out）或左右平移（Truck）。
* **人體比喻**：如同觀眾親自邁步走向被攝者，或與其並肩同行。
* **專屬詳解文檔**：[content/cases/dolly.md](file:///d:/鏡頭語言重點%20工作資料/content/cases/dolly.md)

#### 🎬 經典影視案例與線上影片觀看：

1. **《大白鯊》(Jaws, 1975) —— 影史最經典 Dolly Zoom (推拉變焦)**
   - **導演**：Steven Spielberg (史蒂芬·史匹柏)
   - **官方海報**：[查看大白鯊深海襲來經典海報 (TMDB)](https://image.tmdb.org/t/p/w500/s2VGwxvvsjvJv9v2x48kF84Qp6M.jpg)
   - **經典場景**：警長布羅迪坐在海灘椅上，突然看見海水中浮現血光、孩童遭到鯊魚拖入水底。
   - **鏡頭語言解析**：鏡頭實體向警長臉部 **Dolly In**（物理推進），同時光學變焦鏡頭快速 **Zoom Out**（廣角拉遠）。此時主體面部大小不變，但背後的海灘背景瞬間崩解拉扯，完美視覺化「晴天霹靂、世界在一瞬間崩塌瓦解」的驚恐心理。

## 2. 常見雷區與術語護欄

| 錯誤觀念 / 口誤說法 | 正確影視專業術語 | 本質差異解析 |
| :--- | :--- | :--- |
| ❌「鏡頭往上 Pan 一下」 | ✅ **Tilt Up（垂直仰拍）** | Pan 僅限於水平 Y 軸左右轉動；上下仰俯是 Tilt。 |
| ❌「鏡頭往下 Pan 看地上」 | ✅ **Tilt Down（垂直俯拍）** | 嚴禁將垂直擺動稱為 Pan。 |
| ❌「Dolly 跟 Zoom 差不多」 | ✅ **Dolly（位移視差）vs Zoom（焦距視角）** | Dolly 會產生前後景相對速度不同的視差（Parallax）；Zoom 只是將畫面剪裁放大，透視關係不變。 |
| ❌「相機抬頭就是 Boom」 | ✅ **Tilt（角度改變）vs Boom（高度位移）** | 原地抬頭是 Tilt；整台相機搭電梯垂直上升才是 Boom。 |

## 3. 未來新增資料與保存規範

為了確保所有後續補充的鏡頭語言、作品案例或教學筆記能完整保留，專案遵循以下工作流程：

1. **個別案例專屬文檔**：在 `content/cases/` 資料夾下建立或編輯對應的 Markdown 文件（可參考 [content/cases/template.md](file:///d:/鏡頭語言重點%20工作資料/content/cases/template.md) 範本，包含影片觀賞連結欄位）。
2. **同步更新主文檔**：每次新增案例後，必須同步更新本文件 [index.md](file:///d:/鏡頭語言重點%20工作資料/index.md) 的目錄與案例摘要及影片連結。
3. **前端知識庫同步**：若需在互動網站首頁展示，請同步於 [js/data.js](file:///d:/鏡頭語言重點%20工作資料/js/data.js) 的 `techniques` 物件中追加對應的 `filmCases`（包含 `videoUrl` 與 `embedUrl`），網頁將自動渲染播放按鈕。
4. **恪守術語規範**：任何時候皆嚴格禁止出現「往上 Pan」等不專業用語。
