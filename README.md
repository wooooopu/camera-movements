# CINELANG - 影視鏡頭語言互動網站 (Camera Language Guide)

> 參考資料來源：[Jackson Lin《還在往上 Pan ? 新手該先瞭解的基本鏡頭語言》](https://jacksonlin.net/20190417-%E5%9F%BA%E6%9C%AC%E9%8F%A1%E9%A0%AD%E8%AA%9E%E8%A8%80/)

本專案是一個為動態攝影初學者、影視工作者與導演設計的**鏡頭語言（Cinematic Camera Language）教學與互動展示網站**。旨在透過直觀的「雙重視窗模擬器（HUD Viewfinder + Camera Rig）」與深入淺出的文字拆解，徹底釐清運鏡原理，告別「往上 Pan」等觀念錯誤。

---

## 🌟 專案特色

1. **互動式觀景窗模擬器 (Interactive Viewfinder HUD)**
   - **第一人稱視角 (Director Viewfinder)**：模擬 24 FPS 電影觀景窗、十字對焦、多層次視差運動 (Parallax Depth)。
   - **第三人稱機位 (Camera Rig)**：視覺化展示相機「原地旋轉 (Rotation)」與「實體空間位移 (Translation)」的軌跡差異。
   - 支援即時切換五種運動狀態：`Pan`、`Tilt`、`Boom`、`Dolly` 以及 `Static`。

2. **四大基本運鏡詳解與經典影視案例（海報卡片輪播）**
   - **Pan (水平運鏡)**：機位不動，水平左右搖鏡。《火車大劫案》(1903 首創)、《布達佩斯大飯店》(90°/180° 極速甩鏡)、《羊男的迷宮》(無縫遮擋橫搖轉場)。
   - **Tilt (垂直運鏡)**：機位不動，鏡頭垂直俯仰（向上為 Tilt Up，向下為 Tilt Down，嚴禁稱 Pan！）。《刺激1995》(暴雨救贖仰拍)、《星際效應》(萬丈海嘯極限壓迫)、《教父》(水晶吊燈俯視家族長桌)。
   - **Boom (升降運鏡)**：整機在垂直空間中實體升降。《亂世佳人》(數千傷兵悲歌)、《樂來越愛你》(公路歌舞飛躍)、《大國民》(歌劇院垂直頂棚諷刺)。
   - **Dolly (水平軌道運鏡)**：沿著水平軌道實體位移，配合中廣角強化空間感。《大白鯊》(經典 Dolly Zoom 推拉變焦)、《鬼店》(走廊貼地窒息跟拍)、《原罪犯》(一鏡到底橫向肉搏 Truck)、《全面啟動》(慢速推向旋轉陀螺)。
   - 🎴 **精緻海報卡片輪播 (Card Carousel)**：海報統一採 16:9 比例裁切與劇照覆蓋，點擊海報即可連動喚起彈窗播放電影片段；提供 `›` 與 `‹` 按鈕讓使用者一鍵翻閱下一個案例，版面整齊緊湊不再呈現一長條。

3. **模組化案例庫與資料保存機制 (`content/cases/` & `index.md`)**
   - 建立了專屬的文檔索引 [index.md](file:///d:/鏡頭語言重點%20工作資料/index.md) 與案例分類庫，每份案例皆收錄影片片段觀賞連結。
   - 備有 [template.md](file:///d:/鏡頭語言重點%20工作資料/content/cases/template.md) 範本，未來新增任何運鏡資料、影視作品或影片片段皆能標準化留存。

4. **電影史起源與避坑指南**
   - 收錄 1903 年導演 Edwin S. Porter 與攝影師 Blair Smith 在《火車大劫案》(The Great Train Robbery) 首創 Pan 運鏡的里程碑。
   - 深入剖析 `Pan vs Tilt`、`Tilt vs Boom`、`Dolly vs Zoom` 的本質對比。
   - 貫徹導演思維：「**如果不知該怎麼動，不如不要動**」。

5. **AI 代理友善協作機制 (`AGENTS.md`)**
   - 具備完整的繁體中文 `AGENTS.md` 規範文件，定義了術語護欄（嚴禁「往上 Pan」）、知識體系與程式碼規範，便於 AI Agent 持續擴充與協作。

## 🚀 本地快速預覽與免跳轉直接播放

本專案採用純原生技術（HTML5 + CSS3 + Vanilla ES6 JS），**完全零構建步驟 (Zero Build Dependency)**：

### 🌟 推薦方式：雙擊「一鍵啟動網站預覽」（完美支援直接在頁面播放）
若直接雙擊 `index.html`（`file://` 協定），YouTube 官方會因隱私標頭限制而顯示「錯誤 153」；為了解決此限制：
1. 直接在專案目錄下**滑鼠雙擊 `【一鍵啟動網站預覽】.bat`**（或 `start_preview.bat`）。
2. 電腦會自動啟動本地伺服器並開啟瀏覽器（`http://localhost:8080`）。
3. **所有的電影片段即可直接在頁面上的彈窗內無縫流暢播放，完全不需跳轉至 YouTube，也不會出現錯誤 153！**

### 方法二：直接瀏覽器開啟 (離線快速檢視)
直接在檔案總管中雙擊 `index.html`。彈窗內提供**「▶ 以精準時間軸開啟觀看」**按鈕與時間戳標示，確保 100% 精準跳轉至該電影片段秒數。

### 方法三：透過命令列啟動
如果你習慣使用終端機，可以在專案根目錄執行：

```bash
# 使用 Python 內建伺服器（系統已具備 Python 3）
python -m http.server 8080
```
接著在瀏覽器造訪 `http://localhost:8080` 即可。
