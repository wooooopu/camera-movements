# Assets Directory

此目錄用於放置網站所需的靜態媒體資源：

## 建議放置內容
1. **icons/**: SVG 圖標或相機符號
2. **images/**: 運鏡示意圖、經典電影劇照（如《火車大劫案》歷史劇照、希區考克《迷魂記》劇照）
3. **clips/**: 輕量 WebM / MP4 運鏡短片段示範（Pan / Tilt / Boom / Dolly）

## 資源命名規範
- 小寫英文與連字符號 (kebab-case)，例如：`dolly-in-shock.jpg`, `pan-landscape.webp`
- 圖片建議採用 WebP 格式以提升載入效能。
